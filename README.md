# 🤖 DataFlux-AI – Intelligent Data Query & Analysis Platform

DataFlux-AI is an AI-powered data analysis application that allows users to interact with datasets using natural language and voice input. It converts user queries into SQL, executes them, and displays meaningful insights through an interactive interface.

---

## 🌐 Live Demo

👉 https://dataflux-ai-epaxxdwm7bg52jopjjceyy.streamlit.app/

---

## ✨ Features

* 🎤 Voice-to-text query input
* 💬 Natural language to SQL conversion
* 🧠 AI-powered query generation
* 📊 Data visualization & insights
* 📁 Dataset processing and analysis
* ⚡ Interactive and user-friendly UI

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/PURRAANUSHA/Dataflux-ai.git
cd Dataflux-ai
```

---

### 2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Run the application locally

```bash
streamlit run app.py
```

---

### 4️⃣ Open in browser

```
http://localhost:8501
```

---

## 🚀 How It Works

1. User enters a query (text or voice)
2. The system converts it into SQL using AI
3. SQL is executed on the dataset
4. Results are displayed with insights

---

## ⚠️ Notes

* Voice input may not work in deployed environments due to browser/microphone restrictions
* Recommended to use text input when accessing the live app
